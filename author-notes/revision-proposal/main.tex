\title{Using the Surplus Points in a Lattice Sequence\\
\large Two paths: block-constant and unrestricted point weights}
\author{Working note for the authors}
\date{November 4, 2026}
\begin{document}
\maketitle
\begin{abstract}
There are two distinct paths for using all completed values in a lattice
sequence prefix. Path I assigns one mass to each HKKN12 block, with
equal point weights within that block. In base two there are only
$O(\log n)$ masses; a scalar recursion computes their optimum after
reusable kernel precomputation. Its weights are positive and its
Hilbert-space worst-case error strictly improves on dyadic truncation
at every non-dyadic size. Path II allows all $n$ point weights to vary.
A recursive circulant Schur-complement construction computes that
unrestricted optimum using $O(n\log n)$ solve arithmetic and $O(n)$
storage, after kernel sampling. It can achieve a smaller error, but
positivity is not established. Both structured algorithms here are
derived for binary prefixes; HKKN12's compound-rule framework is
general-base. These are drafts for author review, without verified
novelty or floating-point stability claims. Cancellation, precision
requirements, empirical gains and the limits of the Banach-space
analogy remain part of the research work.
\end{abstract}

\section{Two paths for using the surplus points}\label{sec:paths}
Referees Y and Z identify a substantive issue: an arbitrary-$n$ rate
does not by itself justify using all $n$ values.
Put $M=\lfloor\log_2n\rfloor$ and $N=2^M$.
Keeping only the first $N$ values already gives the known dyadic bound,
while discarding fewer than half the evaluations.
Full nodewise optimized weights can reproduce that rule with zero
weights on the surplus points. Their non-increasing optimal error is
therefore an immediate feasibility fact.

A more focused question is:
\begin{quote}
How cheaply can all completed values be weighted, and what error
reduction is obtained by block-constant weights versus unrestricted
point weights? Can the block path additionally guarantee positivity?
\end{quote}
I recommend centering the revision on the periodic Hilbert-space
quantity $P_{\alpha,2}$, retaining corrected equal-weight Banach analysis
as context. Keep the two spaces and their smoothness parameters explicit:
an improvement in one is not a theorem about the other.

\paragraph{What is already in HKKN12.}
Sections 3.1, 3.3, 4.2 and 4.3 of \cite{HKKN12} give optimal compound
weights, explicit power weights, the base-$b$ block partition, and optimal
compound lattice rules. Proposition 2, pp.~174--176, already reduces a
block covariance from a double sum to a sum over the larger block.
Neither $13=8+4+1$ nor solving the small quadratic optimization problem
is a new construction. Path I specializes this existing class; its possible contribution is
the binary covariance identity, positive scalar recursion and exact
gain over truncation. Path II concerns the larger class of unrestricted
point weights and a recursive FFT computation. Full-lattice FFT solves
are established~\cite{KKKNS22}; the prefix construction below still
needs a literature check. Neither path carries a verified novelty claim.

\paragraph{The two paths at a glance.}
Path I chooses one block mass and shares it equally among that block's
points. Path II chooses one weight for each point; weights within a
block may differ. Both enforce $\sum_iw_i=1$ and minimize the same
Hilbert-space worst-case error over their respective weight classes.

Solve costs assume the required kernel data are available. Sampling
those data costs $O(sn_{\max})$ for either path when a kernel evaluation
costs $O(s)$; Path II also uses an initial FFT. The detailed cache,
per-prefix, repeated-report and stability qualifications are given
in Sections~\ref{sec:blockcost} and~\ref{sec:fftcost}.
The block class is contained in the unrestricted class, so
$e_{\rm full\ opt}\le e_{\rm block\ opt}$.

\paragraph{Scope.}
The two structured algorithms and their proofs below concern $b=2$.
The general HKKN12 block class is recalled in Path I; later references
to other bases concern inherited results and manuscript corrections.
Neither the binary scalar formulas nor the recursive FFT proof is
asserted for arbitrary bases or arbitrary asynchronous subsets.

\section{Common Hilbert-space problem and binary nodes}\label{sec:setup}
For the binary analysis, $b=2$, $\alpha>1$ and $\gamma_j>0$.
Consider the manuscript's periodic Korobov Hilbert space, with
\[
 K(\bx,\by)=\kappa(\bx-\by),\qquad
 \kappa(\bx)=1+\sum_{\bk\ne0}\rho_{\bk}
                e^{2\pi\ii\bk^\top\bx},\qquad
 \rho_{\bk}=\widetilde r(\bk,\boldsymbol{\gamma})^{-2\alpha}>0.
\]
Here $\widetilde r(\bk,\boldsymbol{\gamma})=\prod_{j:k_j\ne0}(|k_j|/\gamma_j)$,
with empty product one. The sum is absolutely convergent and $\int K(\bx,\by)\,d\bx=1$.
Let $e(Q)=\sup_{\|f\|_{\cH}\le1}|Q(f)-I(f)|$.
For node weights summing to one,
\begin{equation}\label{eq:fourier}
 e(Q)^2=\sum_{\bk\ne0}\rho_{\bk}
 \left|\sum_iw_i e^{2\pi\ii\bk^\top\bx_i}\right|^2.
\end{equation}
A common shift $\bDelta$ does not affect this error.

Let $\bx_i=\{\bh\phi_2(i)+\bDelta\}$ be a binary rank-1 lattice sequence,
with an odd coordinate of $\bh$, say $h_1$.
On a finite dyadic horizon containing all prefixes under consideration,
take one coherent integer representative of the generator modulo
that horizon's size; the required horizon is specified below.
An existence theorem for a good infinite generator is not a guarantee
for every software default.
Define
\[
 H_m=\{\bh j/2^m\bmod1:0\le j<2^m\},\qquad
 \mathcal D_m=\{\bk\ne0:\bk^\top\bh=0\bmod2^m\}.
\]
Then $|H_m|=2^m$ and $H_m\subset H_{m+1}$.
For the full equal-weight rule, write
\begin{equation}\label{eq:dm}
 d_m=e(Q_{2^m})^2
 =2^{-m}\sum_{j=0}^{2^m-1}\kappa(\bh j/2^m)-1
 =\sum_{\bk\in\mathcal D_m}\rho_{\bk}.
\end{equation}
Here $d_m>d_{m+1}>0$. For strict decrease, the positive coefficient
at $\bk=2^m\boldsymbol e_1$ is in
$\mathcal D_m\setminus\mathcal D_{m+1}$.

\paragraph{Common pointwise objective.}
Let $G_n=(K(\bx_i,\bx_j))_{i,j=0}^{n-1}$ be the pointwise Gram
matrix. The positive spectrum and distinct nodes make $G_n$ positive
definite. For normalized point weights,
\begin{equation}\label{eq:pointobjective}
 e(Q_w)^2=w^\top G_nw-1,\qquad \bbone^\top w=1.
\end{equation}
Path I restricts $w$ to be constant within each binary block.
Path II minimizes~\eqref{eq:pointobjective} over all normalized $w$.
The kernel, generator, nodes and error criterion are identical in
the two comparisons; the admissible weight vectors differ.

\section{Path I: equal point weights within each block}\label{sec:blockpath}
\paragraph{Equal point weights within HKKN blocks: general base $b$.}
For this general-base paragraph put $M_b=\lfloor\log_b n\rfloor$.
For any integer base $b\ge2$, write
$n=\sum_{m=0}^{M_b} n_m b^m$, with $0\le n_m<b$, and set
$a_m=\sum_{\ell>m}n_\ell b^\ell$.
There are $n_m$ separate blocks of size $b^m$ at level $m$, with
normalized block rules
\[
 Q_{m,q}(f)=\frac1{b^m}
 \sum_{i=a_m+q b^m}^{a_m+(q+1)b^m-1}f(\bx_i),
 \qquad 0\le q<n_m.
\]
Assign a total mass $\theta_{m,q}$ to each block and use
\[
 Q_{\btheta}=\sum_{m=0}^{M_b}\sum_{q=0}^{n_m-1}
 \theta_{m,q}Q_{m,q},\qquad
 \sum_{m,q}\theta_{m,q}=1.
\]
Every point in block $(m,q)$ then has the same weight
$\theta_{m,q}/b^m$; point weights may differ between blocks.
This is the HKKN12 compound-rule class, with
$R=\sum_m n_m\le(b-1)(M_b+1)$ block masses.
Let $A$ be the Gram matrix of the block error functionals
$Q_{m,q}-I$ in the dual Hilbert space. Then
$e(Q_{\btheta})^2=\btheta^\top A\btheta$; for positive definite $A$,
solve $Au=\bbone$ and normalize $\btheta=u/(\bbone^\top u)$
to obtain the block optimum.
HKKN12's Proposition~2 reduces each covariance to one kernel average
over the larger block, rather than a double sum.

\subsection{Binary blocks and their covariance}
Write the nonzero binary digits of $n$ as
\[
 n=N_1+\cdots+N_L,\quad N_r=2^{m_r},\quad
 m_1>\cdots>m_L\ge0,\quad a_r=\sum_{q<r}N_q.
\]
Set $B_r=\{a_r,\ldots,a_r+N_r-1\}$ and
$Q_r(f)=N_r^{-1}\sum_{i\in B_r}f(\bx_i)$.
Megan's block-constant rule is
\begin{equation}\label{eq:compound}
 Q_{\btheta}(f)=\sum_{r=1}^L\theta_rQ_r(f),\qquad
 \sum_r\theta_r=1,\qquad w_i=\theta_r/N_r\quad(i\in B_r).
\end{equation}
The $\theta_r$ are \emph{block masses}, not individual sample weights.
Equal point weights have $\theta_r=N_r/n$;
HKKN12 power weights have $\theta_r=N_r^a/\sum_qN_q^a$;
truncation has $\btheta=(1,0,\ldots,0)$.

\begin{proposition}[Binary block covariance]\label{prop:cov}
Let $A_{rq}=\langle Q_r-I,Q_q-I\rangle_{\cH^*}$.
In decreasing block-size order,
\begin{equation}\label{eq:cov}
 A_{rr}=d_{m_r},\quad
 A_{rq}=c_{m_r}:=2d_{m_r+1}-d_{m_r}\quad(r<q),\quad A_{qr}=A_{rq}.
\end{equation}
Thus $e(Q_{\btheta})^2=\btheta^\top A\btheta$.
Every off-diagonal entry in a given upper row is the same.
\end{proposition}
\begin{proof}
Each block is a shift of $H_{m_r}$. For $r<q$, averaging the kernel over
$H_{m_r}$ and $H_{m_q}$ reduces to an average over $H_{m_r}$,
since $H_{m_q}\subset H_{m_r}$.

There is a further binary simplification. The start of any later block
lies in the other half of the same aligned $2N_r$ interval.
Radical inversion gives
\[
 \phi_2(a_q)-\phi_2(a_r)
 \equiv\frac1{2N_r}\pmod{1/N_r}.
\]
The higher binary digits are unchanged, the digit at level $m_r$
changes from zero to one, and the lower digits contribute multiples
of $1/N_r$. Therefore the cross covariance is
\[
 \frac1{N_r}\sum_{j=0}^{N_r-1}
 \kappa\!\left(\bh\frac{j+1/2}{N_r}\right)-1.
\]
The full $2N_r$ lattice splits into $H_{m_r}$ and this other coset.
Averaging the two cosets proves the off-diagonal formula.
The diagonal follows from shift invariance.
\end{proof}
This specializes HKKN12's Proposition 2 and must be acknowledged as
such. It gives the relevant structure without a Toeplitz assumption on
the pointwise Gram matrix in van der Corput order.

\subsection{Scalar recursion, positivity and error reduction}
The usual HKKN12 expression is
$A^{-1}\bbone/(\bbone^\top A^{-1}\bbone)$.
Equation~\eqref{eq:cov} allows the same optimum to be found without
an inverse or even forming $A$.

\begin{theorem}[Optimal binary block rule]\label{thm:recursion}
The unique minimum of $\btheta^\top A\btheta$ over real $\btheta$ with
$\bbone^\top\btheta=1$ has every component positive.
Define $E_L=d_{m_L}$. For $r=L-1,\ldots,1$, compute
\begin{align}
 D_r&=d_{m_r}+E_{r+1}-2c_{m_r},\label{eq:denom}\\
 t_r&=\frac{E_{r+1}-c_{m_r}}{D_r},\label{eq:tr}\\
 E_r&=\frac{d_{m_r}E_{r+1}-c_{m_r}^{\,2}}{D_r}.\label{eq:Er}
\end{align}
Recover the masses in a forward pass:
\[
 p=1;\quad \theta_r=p\,t_r,\quad p\leftarrow p(1-t_r)
 \quad(r=1,\ldots,L-1);\quad\theta_L=p.
\]
For $L=1$, take $\theta_1=1$. The optimum squared error is $E_1$.
\end{theorem}
\begin{proof}
Let $R$ be any normalized rule supported on blocks after $r$.
All its nodes lie in one shifted other coset of $H_{m_r}$ inside
$H_{m_r+1}$. For each $\bk\in\mathcal D_{m_r}$ the characters at
these nodes have the same phase. Normalization, even for signed weights,
implies $|R(e^{2\pi\ii\bk^\top\cdot})|=1$.
Consequently
\begin{equation}\label{eq:tail}
 e(R)^2\ge d_{m_r}.
\end{equation}
Also $\langle Q_r-I,R-I\rangle=c_{m_r}$, independently of its tail masses.

If the best normalized tail has squared error $v=E_{r+1}$, then the
best error with mass $t$ on block $r$ is
\[
 t^2d_{m_r}+2t(1-t)c_{m_r}+(1-t)^2v.
\]
Since $v\ge d_{m_r}>c_{m_r}$, its quadratic coefficient $D_r$ is
positive, and its minimizer is~\eqref{eq:tr}, strictly between zero and
one. Substitution gives~\eqref{eq:Er}. A tail of total mass zero has
zero cross term with $Q_r$ and nonnegative squared norm; it cannot
improve on $d_{m_r}$ and cannot invalidate this interior optimum.
Backward induction proves the recursion and positivity.

For uniqueness, $A$ is positive definite. A vanishing nonzero combination
of block error representers would give a finite atomic signed measure
with all nonconstant Fourier coefficients zero. It would equal a
multiple of Lebesgue measure, which is impossible for a nonzero finite
atomic measure. Strictly positive $\rho_{\bk}$ and distinct nodes
justify this argument.
\end{proof}

\begin{corollary}[Precise gain over truncation]\label{cor:gain}
If $n$ is non-dyadic, so $L\ge2$, and $M=m_1$, then
\begin{equation}\label{eq:gain}
 e(Q_{\rm block})^2
 =d_M-\frac{4(d_M-d_{M+1})^2}
 {d_M+E_2-2(2d_{M+1}-d_M)}
 <d_M=e(Q_{\rm trunc})^2.
\end{equation}
All $n$ sample weights are positive. Also
\[
 e(Q_{\rm full\ opt})\le e(Q_{\rm block})
 \le e(Q_{\rm HKKN}(a)),\qquad
 e(Q_{\rm block})\le e(Q_{\rm equal}).
\]
If $e(Q_{2^m})\le C\,2^{-\beta m}$ for all relevant $m$, then
$e(Q_{\rm block})\le C\,2^\beta n^{-\beta}$.
\end{corollary}
\begin{proof}
Subtract~\eqref{eq:Er} from $d_M$ and use
$d_M-c_M=2(d_M-d_{M+1})$.
The comparisons follow from feasible weight classes.
For the rate use $2^M>n/2$.
\end{proof}
The rate is already available by truncation and HKKN12.
The useful statements here are positive use of all points, a
\emph{quantified} strict gain, and inexpensive computation.
Worst-case-error inequalities do not order actual errors for every
individual integrand. Nor do they imply that unrestricted nodewise
optimal weights are positive.

\subsection{Precomputation, cost and stability for Path I}\label{sec:blockcost}
\paragraph{Scalar recursion versus dense solves.}
The backward recursion and forward pass cost $O(L)$ arithmetic and
$O(L)$ storage, where $L\le M+1=O(\log n)$.
These counts assume the required $d_m$ values are already available
and produce the $L$ block masses, which represent all point weights
through $w_i=\theta_r/N_r$ on block $r$.
Materializing the full $n$-vector of point weights would itself cost $O(n)$
arithmetic and storage.

For comparison, the same block optimum can always be computed by
solving $Au=\bbone$ and normalizing
$\btheta=u/(\bbone^\top u)$, without explicitly forming $A^{-1}$.
A generic dense Cholesky solve nevertheless costs $O(L^3)$ arithmetic
and $O(L^2)$ matrix storage. The scalar recursion exploits
\eqref{eq:cov} to reduce these to $O(L)$ and $O(L)$, without assembling
$A$. A dense solve for the unrestricted $n$-node optimum costs
$O(n^3)$ arithmetic and $O(n^2)$ matrix storage, and can produce a
different rule. These dense-solve counts exclude matrix assembly;
avoiding an explicit inverse alone does not remove the cubic cost.
These are dense baselines, not lower bounds: Path II below exploits
the full prefix structure to compute the unrestricted optimum in
$O(n\log n)$ solve arithmetic.

\paragraph{One reusable precomputation through $n_{\max}$.}
For a maximum prefix length $n_{\max}\ge1$, set
\[
 J=\lceil\log_2 n_{\max}\rceil,\qquad H=2^J.
\]
Fix a coherent generator through the $H$-point lattice.
The single cache $d_0,\ldots,d_J$ supports every
$1\le n\le n_{\max}$. If $n_{\max}=2^J$, that endpoint has only
one block, and all smaller prefixes use cross covariances involving
at most $d_J$; no value on the next larger lattice is needed.
If $n_{\max}$ is non-dyadic, $H$ is the next larger dyadic size.

The lattices are nested, so evaluate the kernel only on newly added
nodes. With unshifted kernel arguments, accumulate
\[
 S_0=\kappa(\boldsymbol0),\qquad
 S_{m+1}=S_m+\sum_{j=0}^{2^m-1}
 \kappa\!\left(\bh\frac{2j+1}{2^{m+1}}\right),\qquad
 d_m=2^{-m}S_m-1.
\]
Thus the entire cache requires exactly
$1+\sum_{m=0}^{J-1}2^m=H$ kernel evaluations and
\[
 O(sH)=O(sn_{\max})\quad\text{arithmetic},\qquad
 O(J+1)\quad\text{cached scalar storage},
\]
assuming one kernel evaluation costs $O(s)$.
Stream the sums and discard individual kernel values; including the
generator, kernel parameters and one current point, total working
storage is $O(s+J+1)$. Neither all nodes nor a kernel matrix need be
stored. The cache depends on the fixed kernel and generator, not on
$f$, the common shift or the requested prefix length, and is reused
across prefixes and integrands. The kernel evaluations through $H$
require no additional integrand evaluations beyond the completed
prefix. After this precomputation, each requested set of block masses
costs only $O(L)=O(\log n)$ arithmetic and storage.

\paragraph{Integrand sums and requested estimates.}
Keep one function-value sum per active binary block, merging adjacent
equal-sized blocks as new completed values arrive.
Through $n_{\max}$ samples, these merges cost $O(n_{\max})$
arithmetic in total and require $O(1+\log n_{\max})$ aggregate storage.
A requested estimate takes $O(L)=O(\log n)$ once the weights are known.
Reporting after every point through $n_{\max}$ costs
$O(n_{\max}\log n_{\max})$ overall, apart from the reusable
$O(sn_{\max})$ precomputation and integrand evaluation.
Streaming the reports requires no archive of earlier weights or estimates.

\paragraph{Cancellation and numerical validation remain unresolved.}
The operation counts above are for arithmetic at a chosen precision;
they do not establish numerical stability. In particular,
$d_m=2^{-m}S_m-1$ extracts a small residual from an average close to
one. An absolute error $\eta$ in that average can become a relative
error of size $|\eta|/d_m$. This is a practical issue: in the
one-dimensional example with $h=1$, $\alpha=2$ and $\gamma=1$,
$d_{14}=2\zeta(4)2^{-56}\approx3.0\times10^{-17}$, so even the exact
average $1+d_{14}$ rounds to one in binary64 arithmetic.
Compensated summation alone does not recover a residual already lost
in the rounded average.

The determinant subtraction in~\eqref{eq:Er} and the forward
subtraction $1-t_r$ are additional risks. A cancellation-reducing
form of the binary recursion is obtained by setting
\[
 d=d_{m_r},\quad d_+=d_{m_r+1},\quad
 g=d-d_+>0,\quad \delta=E_{r+1}-d\ge0,\quad D=\delta+4g.
\]
Then, equivalently,
\[
 t_r=\frac{\delta+2g}{D},\qquad
 q_r:=1-t_r=\frac{2g}{D},\qquad
 E_r=d_++g\left(\frac{\delta}{D}\right).
\]
Compute $q_r$ directly and use $p\leftarrow p q_r$ in the forward
pass. This avoids the determinant subtraction and the subtraction
of a mass near one. It does not ensure accurate inputs: small
differences $g=d-d_+$ and $\delta=E_{r+1}-d$ still require sufficiently
accurate cached values and tail errors, and tiny masses may underflow.
Possible remedies include higher-precision precomputation or positive
spectral sums, using~\eqref{eq:dm} and
\[
 d_m-d_{m+1}
 =\sum_{\bk\in\mathcal D_m\setminus\mathcal D_{m+1}}\rho_{\bk}>0,
\]
with controlled spectral truncation error. Such remedies may increase
the precomputation cost or the cost per arithmetic operation.
A stable implementation and precision-convergence checks are needed
before claiming reliable floating-point weights or error estimates;
the equivalent formulas alone are not a stability theorem.

The data must form a completed sequence prefix; a failure that loses
values or leaves an arbitrary asynchronous subset is a different
problem. The final prefix length need not be known in advance.

\subsection{Examples and limitations of Path I}
\subsubsection{A thirteen-point example}
In one dimension with $h=1$ and Hilbert smoothness $\alpha=2$,
\[
 d_m=C\,2^{-4m},\qquad C=2\gamma^4\zeta(4).
\]
For $13=8+4+1$, the optimal block masses are
\[
 (\theta_1,\theta_2,\theta_3)
 =\left(\frac{613}{682},\frac{137}{1364},\frac1{1364}\right).
\]
Each of the first eight points has weight $613/5456$,
each of the next four has weight $137/5456$,
and the last point has weight $4/5456$. Exactly,
\[
 e(Q_{\rm block})^2=C\,\frac{4421}{22347776},\qquad
 \frac{e(Q_{\rm block})}{e(Q_{\rm trunc})}
 =\sqrt{\frac{4421}{5456}}\approx0.9002.
\]
This is a sanity check, not high-dimensional evidence.
Positive weights on surplus points can be very small; report that
rather than equating positive use with a large practical benefit.

\subsubsection{Do not promise a universal factor-free bound}
For the same one-dimensional kernel at $n=3$, optimal block masses
are $(9/10,1/10)$ and point weights are $(9/20,9/20,1/10)$.
The squared error is $13C/256$.
The exact dyadic law has leading constant $\sqrt C$ in
$e(Q_{2^m})=\sqrt C\,(2^m)^{-2}$.
Keeping that \emph{same} constant for $n=3$ would require squared
error at most $C/81$, but $13/256>1/81$.

Thus~\eqref{eq:gain} improves the actual truncated Hilbert error;
it does not remove the entire $(n/2^M)^\alpha$ loss in the strongest
sense. Referee Z's displayed (T) concerns $P_\alpha$ and the quoted
Banach bound. This note addresses its Hilbert analogue; it does not
prove a sharper $P_\alpha$ bound by changing notation.

\subsubsection{A Banach-space obstruction}
In the one-dimensional Banach space of the manuscript, put
$C_\alpha=2\gamma^\alpha\zeta(\alpha)$ and
$q=2^{-\alpha}<1/2$.
For $n=3$, assign mass $1-t$ to the first two points and $t$ to
the singleton. Split Fourier modes into odd integers, integers
divisible by two but not four, and multiples of four. This gives
\begin{equation}\label{eq:banach}
 P_\alpha(t)=C_\alpha
 [q^2+q(1-q)|1-2t|+(1-q)|t|].
\end{equation}
On $0\le t\le1/2$ its increase from $t=0$ is
$C_\alpha(1-q)(1-2q)t>0$.
For $t<0$ it decreases towards zero; for $t>1/2$ it increases.
The unique minimum over real $t$ is truncation, $t=0$.
This block family cannot strictly improve the exact Banach truncation
error at every non-dyadic $n$, even though it can in the Hilbert space.
That distinction should shape the revised paper.

\section{Path II: unrestricted point weights by recursive FFT solves}\label{sec:fftpath}
\subsection{The full optimum and what it guarantees}
There are $n$ independent point-weight variables before normalization;
weights in the same HKKN12 block need not agree. Lagrange multipliers
in~\eqref{eq:pointobjective} give
\begin{equation}\label{eq:fullweights}
 G_nu=\bbone,\qquad
 w_{\rm full}=\frac{u}{\bbone^\top u},\qquad
 e_{\rm full}^2=\frac1{\bbone^\top u}-1.
\end{equation}
The last expression is an exact identity, not a recommendation for
floating-point error evaluation. No explicit matrix inverse is needed.
A generic dense implementation costs $O(sn^2+n^3)$ arithmetic and
$O(n^2)$ matrix storage. The structure below gives a cheaper direct
solve for binary lattice prefixes, without imposing block-constant weights.

Every block-constant rule is feasible here. Hence the full optimum has
error no larger than the Path I optimum, and inherits its strict
improvement over truncation at non-dyadic $n$. Its error is non-increasing
as points are added, since a new weight may be set to zero.
These facts do not establish positive weights at all points.
At a full dyadic size, circulant symmetry gives $w_i=1/n$ immediately.

\paragraph{A small example where the paths differ.}
In the one-dimensional $\alpha=2$, $h=1$ example, the first five
points in sequence order are $(0,1/2,1/4,3/4,1/8)$, before a common shift.
Their two optimal weight vectors are exactly
\[
 w_{\rm block}=\frac1{552}(137,137,137,137,4),\qquad
 w_{\rm full}=\frac1{544}(117,139,117,139,32).
\]
The first four points form one block: their weights agree in Path I
and differ in Path II. With $C=2\gamma^4\zeta(4)$,
\[
 e_{\rm block}^2=C\frac{363}{94208},\qquad
 e_{\rm full}^2=C\frac{121}{34816},\qquad
 \frac{e_{\rm full}^2}{e_{\rm block}^2}=\frac{46}{51}.
\]
This exact small example distinguishes the two feasible classes;
it does not establish a typical gain or positivity in general.

\subsection{Circulant embedding and recursive elimination}
For the requested prefix, put $H=2^{\lceil\log_2n\rceil}$ and evaluate
\[
 c_j=\kappa(\bh j/H),\qquad
 C_H=(c_{(i-j)\bmod H})_{i,j=0}^{H-1}.
\]
The full-grid matrix $C_H$ is positive definite and circulant;
full-lattice FFT diagonalization is standard~\cite{KKKNS22}.
Let $\operatorname{rev}_H(i)$ reverse the $\log_2H$ binary digits
of $i$. The original sequence prefix selects natural-grid indices
$\operatorname{rev}_H(0),\ldots,\operatorname{rev}_H(n-1)$.
Thus $G_n=P_{n,H}C_HP_{n,H}^\top$, where $P_{n,H}$ selects these
indices in sequence order. A common shift cancels in kernel differences.

\begin{proposition}[Recursive prefix solve in exact arithmetic]\label{prop:fft}
Given the positive Fourier eigenvalues of $C_H$, a linear system
$G_nu=f$ with any right-hand side can be solved by recursive circulant
elimination in $O(H\log H)=O(n\log n)$ arithmetic and $O(H)=O(n)$
working storage. The singleton case is handled directly.
\end{proposition}
\begin{proof}
At each recursive stage, $H$ denotes the current ambient dyadic size.
The bit-reversal identities
\[
 \operatorname{rev}_{2N}(i)=2\operatorname{rev}_N(i),\qquad
 \operatorname{rev}_{2N}(N+i)=2\operatorname{rev}_N(i)+1
 \quad(0\le i<N)
\]
give the two recursion cases. If $n\le H/2$, the prefix lies entirely
in the even subgroup; restrict the circulant to that subgroup and
halve $H$. If $n=H$, solve the full circulant system by FFT.

Otherwise write $H=2N$ and $n=N+r$, $0<r<N$.
The prefix contains all $N$ even-grid nodes and a bit-reversal prefix
of $r$ odd-grid nodes. In natural even/odd order,
\[
 C_{2N}=\begin{pmatrix} A&B\\ B^\top&A\end{pmatrix},
 \qquad
 \widehat G_n=
 \begin{pmatrix} A&BP^\top\\ PB^\top&PAP^\top\end{pmatrix},
\]
where $A,B$ are circulant of size $N$, $P$ selects the $r$ odd-grid
indices, and $\widehat G_n$ is $G_n$ after reordering the complete
first block into natural order. The right-hand side is reordered
in the same way. Define the full Schur circulant
\begin{equation}\label{eq:schur}
 S=A-B^\top A^{-1}B.
\end{equation}
Circulants are closed under these operations, and $S$ is positive
definite as a Schur complement of $C_{2N}$.
For a reordered right-hand side $(f_0,f_1)$, compute
\[
 v=A^{-1}f_0,\qquad
 (PSP^\top)y=f_1-PB^\top v,\qquad
 x=v-A^{-1}BP^\top y.
\]
All appearances of $A^{-1}$ mean FFT-based solves, not a formed
inverse. The remaining matrix $PSP^\top$ is another bit-reversal
prefix of a circulant of half the ambient size. Its effective
kernel has changed to $S$; the original $d_m$ cache does not describe it.
Recurse, back substitute and restore sequence order.

Every ambient size halves. There are a constant number of FFTs and
linear spectral operations per stage, giving
\[
 \sum_{j\ge0}O\!\left(\frac{H}{2^j}
                      \log\frac{H}{2^j}\right)=O(H\log H).
\]
The arrays across all stages have geometric total length $O(H)$.
No dense pointwise matrix or explicit inverse is required.
\end{proof}

\subsection{Spectral formulas and cancellation precautions}
Use the unnormalized DFT convention
$\lambda_k=\sum_{j=0}^{2N-1}c_j e^{-2\pi\ii kj/(2N)}>0$.
The even-subgroup and Schur spectra are respectively
\begin{equation}\label{eq:pairedspectra}
 a_k=\frac{\lambda_k+\lambda_{k+N}}2,\qquad
 \sigma_k=\frac{2\lambda_k\lambda_{k+N}}
                 {\lambda_k+\lambda_{k+N}},
 \qquad 0\le k<N.
\end{equation}
For the displayed even/odd convention, the cross-block eigenvalues are
\[
 \beta_k=e^{-\pi\ii k/N}
          \frac{\lambda_k-\lambda_{k+N}}2.
\]
Thus all eliminations and back substitutions use pointwise spectral
operations and FFTs. Compute the Schur spectrum by its positive
harmonic-mean expression, rather than the subtraction
$a_k-|\beta_k|^2/a_k$. A scaled form is
$\sigma_k=2\ell_k/(1+\ell_k/h_k)$, with
$\ell_k=\min(\lambda_k,\lambda_{k+N})$ and
$h_k=\max(\lambda_k,\lambda_{k+N})$.
The identities follow from
$a_k^2-|\beta_k|^2=\lambda_k\lambda_{k+N}$.
For a constant right-hand side, compute its reduced multiplier as
$2\lambda_N/(\lambda_0+\lambda_N)$, avoiding subtraction of a ratio
near one.

These formulas reduce local cancellation; they do not establish
stability. The initial FFT can lose tiny positive eigenvalues, and
back substitution, normalization and error evaluation can expose
conditioning or cancellation. Computed nonpositive eigenvalues must
be diagnosed, not silently clipped. Accurate positive spectra or
higher precision may be required, increasing the cost per operation
or the kernel-precomputation cost.

There is also a positive error-evaluation identity. Embed normalized
weights into the full grid as $z=P_{n,H}^\top w$, and let $\widehat z$
be its unnormalized DFT. Since $\widehat z_0=1$,
\begin{equation}\label{eq:positiveerror}
 e(Q_w)^2=d_{\log_2H}
       +\frac1H\sum_{k=1}^{H-1}\lambda_k|\widehat z_k|^2.
\end{equation}
This avoids the final subtraction in $w^\top G_nw-1$ or
\eqref{eq:fullweights}, provided the cached dyadic error and spectrum
are accurate. It applies to either normalized weight class and does
not repair inaccurate inputs. A full floating-point analysis remains open.

\subsection{Precomputation and cost for Path II}\label{sec:fftcost}
At one requested $n$, sampling the $H<2n$ kernel values costs $O(sn)$;
the initial FFT and recursive solve cost $O(n\log n)$. Including
the generator and kernel parameters, total working storage is
$O(s+n)$. No extra integrand values are needed at the enclosing
full-lattice nodes.

To support every prefix through $n_{\max}$, set
$H_{\max}=2^{\lceil\log_2n_{\max}\rceil}$.
Sample one full kernel column in $O(sn_{\max})$ arithmetic and
transform it in $O(n_{\max}\log n_{\max})$ arithmetic.
Cache the spectra for \emph{every} smaller dyadic horizon using the
arithmetic means in~\eqref{eq:pairedspectra}. These reductions cost
$O(H_{\max})$ arithmetic and retain only
$1+2+4+\cdots+H_{\max}=2H_{\max}-1=O(n_{\max})$ values.
Each request can then start at its own smallest enclosing grid and
has $O(n\log n)$ solve cost. Keeping only the largest spectrum and
reducing it afresh can instead cost $O(n_{\max})$ even for a small request.

The weights depend on the nodes and kernel, not on the integrand;
once computed for a prefix they can be reused, with $O(n)$ arithmetic
to apply them. Independently recomputing unrestricted weights after
\emph{every} point through $n_{\max}$ has the straightforward bound
$O(n_{\max}^2\log n_{\max})$, apart from reusable precomputation.
No cheaper all-prefix update bound is claimed. This differs from
Path I's $O(n_{\max}\log n_{\max})$ repeated-report cost and
logarithmic aggregate storage.

\paragraph{Validation status.}
The recursive construction is a draft exact-arithmetic argument for
author review; no novelty or numerical-stability claim is made.
The companion \texttt{verify\_fft\_prefixes.py} supplies a standard-Python
prototype and small comparisons with independent dense solves,
including unrestricted weights and the block-optimum error bound.
Passing those checks verifies identities and indexing on the tested
cases; it does not establish conditioning, high-dimensional performance
or safe binary64 arithmetic at large horizons.

\section{Validation and experiments comparing the two paths}
This is a proposed protocol, not completed large-scale experimentation.
The two companion programs validate small exact block identities and
small floating-point FFT solves, respectively; neither is a completed
performance or stability study.

\begin{enumerate}
\item \textbf{Methods.}
Use identical nodes and the same kernel for equal point weights;
truncation at $2^{\lfloor\log_2n\rfloor}$; HKKN12 power masses with
$a=2,3,4$; Path I's recursive optimal block rule; and Path II's
recursive FFT unrestricted optimum, always enforcing normalization.
At small $n$, compare each fast method with its own dense reference:
the $L\times L$ HKKN12 solve for Path I and the $n\times n$
pointwise solve for Path II. Each pair must agree. The two paths
solve different optimizations and need not give the same weights.

\item \textbf{Smoothness, dimensions and budgets.}
Use Hilbert $\alpha=2$ as the primary case, add $\alpha=3$, and retain
$\alpha=1$ only as context.
For example, use $s=2,6,20$ with two declared coordinate-weight decays.
Scan every $n$ to a modest horizon such as $2^{12}$, then prespecify
larger budgets. Include $2^M+1$, $2^{M+1}-1$, $13\cdot2^p$, and
different binary digit counts, rather than favorable prefixes only.
A common finite generator need not be good for every kernel:
report the common-generator comparison and, if available,
tuned-generator comparisons separately.

\item \textbf{Worst-case-error outputs.}
Plot $e_{\rm method}/e_{\rm trunc}$ against both $n$ and
$n/2^{\lfloor\log_2n\rfloor}$, marking powers of two.
Include ratios to HKKN12 power weights and to the full nodewise
optimum. Report ratio distributions and maxima, not only chosen curves.
Separate $e$ and $e^2$. Time precomputation, weight calculation, and
application separately; record memory and arithmetic precision.
Within each path, agreement with its dense optimum is verification;
the gain in computing cost is the algorithmic comparison. Between
paths, compare worst-case error, point-weight signs and the cost of
retaining or recomputing weights.

\item \textbf{Integrands and uncertainty.}
Use smooth periodic products
$f(\bx)=\prod_j[1+\eta_j\cos(2\pi x_j)]$, with integral one and finite
Fourier support, and a broader-spectrum periodic example with a
checked finite Hilbert norm.
For actual-integrand comparisons use paired common random shifts,
for example at least 32 independent shifts, with absolute-error
summaries. Shifts do not change this periodic worst-case error,
so they are not replicate worst-case-error experiments.
Keister may be an application illustration, but the transformed
integrand's endpoint regularity and norm must be checked before
claiming it belongs to the theoretical space.
Protect actual-error ratios against a zero truncated denominator.

\item \textbf{Reproducibility and numerical checks.}
Record generator entries or an archived file and checksum, residue
horizon, ordering, kernel scaling, coordinate weights, seeds, software,
precision, and scripts.
Check $\sum_iw_i=1$ for both paths. For Path I check positivity,
\eqref{eq:cov} and $A\btheta-E_1\bbone$. For Path II check the
linear-system residual, stationarity $G_nw-\lambda\bbone$,
agreement with the dense full optimum, and $e_{\rm full}\le e_{\rm block}$;
report weight signs rather than assuming positivity.
Use precision-convergence checks for tiny eigenvalues, discrepancies
and weights, and compare error formulas including~\eqref{eq:positiveerror}.
Do not silently clip negative roundoff discrepancies or eigenvalues.
\end{enumerate}

derivation under review. State why the Hilbert norm and measured gains matter.

\paragraph{Correctness and scope (X and Y).}
Specify $\alpha>1$ where Banach Fourier summability is required.
The replacement of $r(k,\gamma_j)$ by $\max(1,|k|/\gamma_j)$
needs $\gamma_j\le1$; retain that assumption or remove the replacement.
Restore the missing $(b-1)$ in the logarithm-free bound.
State existence and generator quantifiers consistently in inherited
bounds, and audit base restrictions against HN03 \cite{HN03}.

For general base $b$, a repeated digit represents several blocks with
different shifts, not a single phase times a digit.
With $a_\ell=\sum_{t>\ell}n_tb^t$, the correct character decomposition is
\[
 \frac{e^{2\pi\ii\bk^\top\bDelta}}{n}
 \sum_{\ell=0}^M\sum_{q=0}^{n_\ell-1}
 b^\ell\bbone_{\{\bk^\top\bh=0\bmod b^\ell\}}
 e^{2\pi\ii\bk^\top\bh\phi_b(a_\ell+qb^\ell)}.
\]
This preserves the triangle bound and covers Y's $b=3,n=2$ example.
Correct the misplaced power in the denominator, extra parentheses,
duplicated alignment end, and missing wavenumber inner product
in the Hilbert Fourier expansion.

\paragraph{Normalization and the visible numerical code.}
For unnormalized weights the identity is
$e(w)^2=1-2\bbone^\top w+w^\top Kw$.
Only with $\bbone^\top w=1$ may it become $w^\top Kw-1$.
The visible \texttt{Programs/discrepancy.m} currently solves
$u=K^{-1}\bbone$ and uses the former expression without normalization.
That differs from the constrained optimum derived in the manuscript.
Audit figure provenance before interpreting existing plots.
The constrained optimum uses $w=u/(\bbone^\top u)$;
solve a system rather than explicitly forming an inverse.

Also, \texttt{GramMat.m} uses a $B_2$ factor with coefficient
$\texttt{coordwts}_j/2$.
Under the manuscript's $\alpha=1$ convention the coefficient is
$2\pi^2\gamma_j^2$. They agree only when
$\texttt{coordwts}_j=4\pi^2\gamma_j^2$.
For integer Hilbert $\alpha$, the intended factor is
\[
 1+\frac{(-1)^{\alpha+1}(2\pi\gamma_j)^{2\alpha}}{(2\alpha)!}
 B_{2\alpha}(\{x_j-y_j\}).
\]
The existing $B_2$ routine does not supply an $\alpha=2$ experiment.

Positive Block Rules and Unrestricted Point Weights}.

\item Binary blocks and the periodic Hilbert setting, with HN03 and

Megan's current work could connect to the block covariance calculation,
